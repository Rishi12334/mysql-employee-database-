# mysql-employee-database-
## Overview

This project is a hands-on MySQL practice exercise built around an employee database with three related tables: `departments`, `location` and `employees`. It is split into two assignments:

- **Assignment 1** covers DDL commands (`CREATE`, `ALTER`, `RENAME`, `TRUNCATE`, `DROP`) and constraints such as primary keys, foreign keys, `UNIQUE`, `NOT NULL`, `CHECK` and `AUTO_INCREMENT`.
- **Assignment 2** covers querying data with `DISTINCT`, aliases, `WHERE`, `ORDER BY`, `LIMIT`, aggregate functions, `GROUP BY`, `HAVING`, and inner, left and right joins.

The sample data has 13 departments, 4 locations and 30 employees
